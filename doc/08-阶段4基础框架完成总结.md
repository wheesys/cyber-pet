## 二、全局方案：路径解析（便携优先）

> CLAUDE.md 要求「软件足够绿色，删除目录即彻底卸载」，与架构文档原定的
> `~/.cyber-pet/logs/` 全局目录存在冲突。本阶段确立统一策略并落地到 `paths` 模块。

### 2.1 路径策略

| 模式 | 触发条件 | 数据根目录 |
|------|----------|-----------|
| 便携模式（默认） | 可执行文件同级目录可写 | `<exe_dir>/data/` |
| 安装模式（回退） | 便携目录不可写 | `~/.cyber-pet/` |
| 兜底 | 主目录也不可用 | `./data/` |

### 2.2 目录结构

```
<data_root>/
├── config/app.toml     # 应用配置（TOML）
├── logs/cyber-pet.log  # 日志（按天轮转）
└── db/                 # 数据库（阶段5 接入）
```

### 2.3 实现要点（src-tauri/src/paths/mod.rs）

- `data_root()`：`OnceLock` 缓存，首次探测文件系统后固定，避免重复 IO。
- `is_writable()`：通过创建 `.write_probe` 探针文件判定目录可写性。
- `logs_dir()` / `config_dir()` / `db_dir()`：统一派生子目录，供各模块复用（DRY）。

## 三、窗口管理系统（阶段4.1）

### 3.1 系统托盘（src-tauri/src/window/mod.rs）

- `setup_tray()`：创建托盘图标 + 菜单。
- 菜单项：显示/隐藏宠物、退出；菜单 ID 用常量统一管理。
- 交互：右键弹菜单，左键单击切换宠物显隐。

### 3.2 窗口命令（src-tauri/src/commands/mod.rs）

| 命令 | 作用 |
|------|------|
| `start_drag` | 系统级窗口拖拽（性能优于 JS 逐帧定位） |
| `set_always_on_top` | 设置窗口置顶 |
| `set_window_position` | 设置窗口物理像素位置 |

### 3.3 前端（src/App.tsx + App.css）

- 透明窗口下的可拖拽宠物占位（阶段5 替换为 Pixi.js Sprite）。
- 舞台 `pointer-events: none` + 宠物本体 `pointer-events: auto`，
  保证仅宠物可交互、窗口其余区域鼠标穿透。

## 四、配置管理系统（阶段4.2）

### 4.1 配置模型（src-tauri/src/config/mod.rs）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| version | u32 | 1 | 配置结构版本，用于迁移 |
| theme | String | "system" | 主题：light/dark/system |
| language | String | "zh-CN" | 界面语言 |
| auto_start | bool | false | 开机自启 |
| p2p_enabled | bool | false | P2P 接入（**默认关闭**，符合安全要求） |

### 4.2 特性

- **格式**：TOML，人可读、易手改。
- **默认生成**：首次启动无配置文件时自动生成并落盘。
- **向前兼容**：`#[serde(default)]` 保证旧配置文件缺失字段时回退默认值。
- **健壮性**：配置损坏时回退默认值并告警，不阻塞启动、不覆盖原文件。
- **命令**：`get_config`（读内存 state）、`set_config`（写盘 + 更新 state）。

### 4.3 单元测试

3 个测试覆盖：默认值安全性（P2P/自启默认关闭）、TOML 往返、部分字段回退默认。

## 五、日志系统（阶段4.3）

### 5.1 实现（src-tauri/src/logging/mod.rs）

- **框架**：tracing + tracing-subscriber + tracing-appender。
- **级别**：ERROR/WARN/INFO/DEBUG；环境变量 `CYBER_PET_LOG` 可覆盖默认级别。
- **默认级别**：debug 构建 = debug，release = info。
- **输出**：控制台（带颜色）+ 文件（非阻塞、无颜色码）双通道。
- **轮转**：按天轮转，文件名形如 `cyber-pet.log.2026-05-31`。
- **健壮性**：日志目录创建失败时退化为仅控制台输出，不 panic。

### 5.2 生命周期

`logging::init()` 返回的 `WorkerGuard` 存入 App state，
保证非阻塞写入线程在程序退出前刷新缓冲，避免日志丢失。
